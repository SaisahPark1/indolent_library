Description:
 - An error handler for any api for safety nets and ease of use. Added into other kits to safely escape server stops.

Install:
 - npm i

Usage:

API:
 - This error handling is necessary to keep a database healthy and keep problems readable and stoppable. Otherwise one error could stop the whole server.
